## 💡 Quick Copy-Paste Guide for University Portal
For each week on the university submission form:
1. Select the **Week** from the dropdown (`Week 1` to `Week 12`).
2. Paste the corresponding **GitHub / Report Link** from the table above.
3. Open the corresponding `Week-XX.md` file to copy the formatted **Work Completed**, **Problems Faced**, and **Plan for Next Week** texts.
4. Click **Submit Weekly Report**.
